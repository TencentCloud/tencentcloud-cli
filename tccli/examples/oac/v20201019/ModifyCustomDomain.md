Input: 

```
tccli oac ModifyCustomDomain --cli-unfold-argument  \
    --ServiceId 1 \
    --Domain 1 \
    --OptionsKey 1 \
    --OptionsValue 1 \
    --Skey xxx
```

```
{
    "Response": {
        "RequestId": "f2c3d65d-ec30-4f8a-b10c-b4a24ffcd58d"
```
