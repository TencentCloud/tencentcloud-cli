Input: 

```
tccli monitor QueryMetrics --cli-unfold-argument  \
    --Namespace QCE/CVM \
    --MetricName CpuUsage \
    --StartTime 2026-03-30T20:08:24+08:00 \
    --EndTime 2026-03-30T21:08:24+08:00 \
    --Period 300 \
    --Aggregation.Statistic avg \
    --Aggregation.Dimensions InstanceId \
    --Regions ap-guangzhou
```
