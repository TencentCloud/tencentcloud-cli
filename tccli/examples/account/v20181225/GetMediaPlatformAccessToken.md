**Example 1: 获取微信公众号access_token**



Input: 

```
tccli account GetMediaPlatformAccessToken --cli-unfold-argument  \
    --Username xxxx \
    --AppID xxxx
```

Output: 
```
{
    "Response": {
        "AppID": null,
        "Username": null,
        "AccessToken": null,
        "FuncScope": null,
        "RequestId": "198419cc-886c-4ea8-836f-ebac69087d3d"
    }
}
```
