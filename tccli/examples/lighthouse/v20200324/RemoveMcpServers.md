**Example 1: 删除MCP Server**

删除指定实例下的MCP Server。

Input: 

```
tccli lighthouse RemoveMcpServers --cli-unfold-argument  \
    --InstanceId lhins-lart4xxz \
    --McpServerIds lhms-oartxxxz
```

Output: 
```
{
    "Response": {
        "RequestId": "42582c39-52fd-4a00-8019-c3c995e8f9d6"
    }
}
```
