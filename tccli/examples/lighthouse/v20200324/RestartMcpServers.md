**Example 1: 重启MCP Server**

重启指定实例下的MCP Server。

Input: 

```
tccli lighthouse RestartMcpServers --cli-unfold-argument  \
    --InstanceId lhins-ruy9d2tw \
    --McpServerIds lhms-oartxxxz
```

Output: 
```
{
    "Response": {
        "RequestId": "42582c39-52fd-4a00-8019-c3c995e8f9d6"
    }
}
```
